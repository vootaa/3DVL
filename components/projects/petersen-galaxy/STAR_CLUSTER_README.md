# Petersen Galaxy - 恒星群组件

## 概述

为 Petersen Galaxy 项目新增了一个恒星群组件，按照指定的极坐标数据在三个轨道上精确放置了20颗恒星。

## 功能特点

### 🌟 恒星配置
- **总数**: 20颗恒星
- **轨道**: 3个同心圆轨道
- **类型**: 三种不同的恒星类型，基于真实天体物理学

### 🎨 视觉效果

#### 恒星类型与颜色
1. **主序星** (内轨道, r=1.5)
   - 颜色: 金色 (#FFD700)
   - 类型: G型主序星，类似太阳
   - 数量: 5颗

2. **蓝巨星** (中轨道, r=3.0)
   - 颜色: 蓝白色 (#87CEEB)
   - 类型: B型蓝巨星，大质量高温恒星
   - 数量: 5颗

3. **红巨星** (外轨道, r=4.8)
   - 颜色: 橙红色 (#FF4500)
   - 类型: M型红巨星，演化后期巨大恒星
   - 数量: 10颗

#### 高级着色器效果
- **多层发光**: 核心、内层光晕、外层光晕
- **动态闪烁**: 基于多频率正弦波的真实恒星闪烁
- **颜色脉冲**: 微妙的颜色温度变化
- **大小变化**: 基于恒星类型的真实大小差异

### 🎮 交互控制

#### 恒星控制面板
位于右上角的控制面板提供以下功能：

1. **显示/隐藏恒星**: 切换整个恒星群的可见性
2. **恒星信息**: 显示详细的恒星统计和类型说明

#### 信息面板内容
- 恒星总数和轨道信息
- 各类型恒星的数量统计
- 恒星类型的科学说明
- 颜色编码的图例

## 技术实现

### 组件结构
```
components/projects/petersen-galaxy/
├── StarCluster.vue          # 主恒星群组件
├── StarControl.vue          # 恒星控制面板
├── star-cluster-config.ts   # 恒星配置文件
└── shaders/
    ├── star-vertex.glsl     # 恒星顶点着色器
    └── star-fragment.glsl   # 恒星片段着色器
```

### 核心技术
- **Three.js Points**: 高性能的点云渲染
- **自定义着色器**: WebGL着色器实现高质量视觉效果
- **实时动画**: 60FPS的流畅动画循环
- **响应式设计**: Vue 3 Composition API

### 恒星数据
按照用户提供的精确极坐标数据放置：

| ID | 极坐标 (r, θ) | 轨道 | 类型 |
|----|--------------|------|------|
| 0-4 | r=3.0, θ=0°-288° | 中轨道 | 蓝巨星 |
| 5-9 | r=1.5, θ=0°-288° | 内轨道 | 主序星 |
| 10-19 | r=4.8, θ=62°-350° | 外轨道 | 红巨星 |

## 使用方法

### 基本使用
恒星群组件会自动集成到 Petersen Galaxy 项目中，默认显示状态。

### 控制操作
1. **查看恒星**: 右上角控制面板，默认开启
2. **查看信息**: 点击"恒星信息"按钮查看详细统计
3. **隐藏恒星**: 点击"隐藏恒星"按钮关闭显示

### 观察技巧
- 使用鼠标滚轮缩放以观察不同距离的效果
- 拖拽鼠标旋转视角查看完整的三维分布
- 近距离观察可以看到恒星的发光层次效果

## 性能优化

- 使用高效的 BufferGeometry 和 Points 渲染
- 着色器在 GPU 上执行，减少 CPU 负载
- 适度的粒子数量（20颗）确保流畅性能
- 条件渲染避免不必要的计算
